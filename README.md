# Binarium Screenshot Analyzer — Telegram bot

Публічний Telegram-бот, який приймає скриншоти графіків і повертає обережний технічний розбір українською мовою: `CALL`, `PUT` або `НЕ ВХОДИТИ`.

## Що вміє

- Приймає фото та файли-зображення PNG/JPEG/WebP.
- Перевіряє роздільність, контраст і структуру зображення через OpenCV.
- За наявності `GEMINI_API_KEY` передає зображення до Gemini vision-моделі для опису того, що реально видно на графіку.
- Аналізує лише видимі індикатори; не вигадує значення RSI/MACD, якщо вони нечитабельні або не показані.
- Видає актив/таймфрейм, видимий тренд, докази за/проти, рівні, якість графіка та причини не входити.
- Обмежує частоту запитів: за замовчуванням 15 секунд між аналізами та 30 аналізів за 24 години на користувача.

## Важливі обмеження

1. **Немає гарантії точності або прибутку.** Один скриншот не містить повної історії OHLC і не дає надійно обчислити RSI/MACD, якщо значення індикаторів не видно. Відповідь AI — інтерпретація зображення, а не перевірений прогноз.
2. **Це не підключення до Binarium.** Бот не отримує котирування в реальному часі від Binarium і не відкриває угоди.
3. **Gemini API.** Потрібен ключ Google AI Studio. Доступність безкоштовної квоти, моделей, лімітів і умов обробки даних змінюється. Якщо квота вичерпана або модель недоступна, бот повідомить про помилку й не повинен використовуватися як джерело сигналу.
4. **Безкоштовний Render не гарантує 24/7.** Безкоштовний web service засинає після періоду без вхідного трафіку, може запускатися із затримкою й може перезапускатися. Telegram webhook може бути затриманий, поки сервіс прокидається. Для безперервної роботи потрібен хостинг без sleep/з відповідним SLA, який може бути платним.
5. **Обмеження спільного публічного бота.** Поточний rate limiter зберігається в пам'яті, тому скидається після перезапуску та не синхронізується між кількома інстансами. Для великої аудиторії додайте базу даних, чергу завдань і централізовані ліміти.
6. **Приватність.** Якщо налаштовано Gemini, зображення передається Google Gemini API. Не просіть користувачів надсилати особисті/платіжні дані. Ознайомтеся з чинними умовами Telegram і Google.

## 1. Створіть Telegram-бота

1. Відкрийте Telegram і знайдіть `@BotFather`.
2. Надішліть `/newbot`, задайте ім'я та username.
3. Скопіюйте токен. Це секрет: не публікуйте його та не додавайте до GitHub.

## 2. Отримайте ключ для AI-аналізу

1. Відкрийте Google AI Studio: https://aistudio.google.com/
2. Створіть API key.
3. Перевірте актуальні доступні моделі та квоти у своєму акаунті. За замовчуванням використовується `gemini-2.5-flash`; якщо модель недоступна, задайте `GEMINI_MODEL` на назву vision-моделі, доступної для вашого ключа.
4. Не вважайте «безкоштовну квоту» необмеженою або гарантованою.

## 3. Безкоштовне розгортання на Render

### Через GitHub

1. Розпакуйте ZIP і завантажте файли в новий приватний або публічний GitHub-репозиторій. Не додавайте реальні API-ключі.
2. Зареєструйтеся на https://render.com/
3. Виберіть **New → Blueprint** і під'єднайте репозиторій із `render.yaml` (або створіть **New → Web Service**, Runtime Python).
4. Якщо створюєте сервіс вручну:
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
   - Health Check Path: `/`
   - Plan: Free
5. Після створення скопіюйте публічну HTTPS-адресу сервісу, наприклад `https://your-service.onrender.com`.
6. У Render → Environment додайте:
   - `BOT_TOKEN` — токен від BotFather
   - `GEMINI_API_KEY` — ключ Google AI Studio
   - `GEMINI_MODEL` — модель vision, доступна вашому ключу
   - `PUBLIC_BASE_URL` — точна HTTPS-адреса сервісу без слеша в кінці
   - `WEBHOOK_SECRET` — довгий випадковий секрет (Render може згенерувати його з `render.yaml`)
7. Збережіть змінні та зробіть redeploy. У логах шукайте `Telegram webhook configured`.
8. Відкрийте адресу сервісу в браузері. Має повернутися `{"status":"ok","service":"binarium-screenshot-analyzer"}`.
9. Відкрийте бота в Telegram, натисніть Start і надішліть тестовий скриншот.

**Якщо змінюєте домен:** оновіть `PUBLIC_BASE_URL` та зробіть redeploy. Код встановлює Telegram webhook під час старту.

### Чому безкоштовний хостинг не означає 24/7

Render Free засинає після приблизно 15 хвилин без вхідного HTTP-трафіку; пробудження може тривати близько хвилини. Платформа також може перезапускати інстанс, а ліміти використання можуть призвести до призупинення сервісу. Тому не обіцяйте користувачам миттєву доступність у будь-яку секунду. Не використовуйте сторонні «пінгери», щоб обходити обмеження тарифу.

## 4. Локальний запуск для тестування

Потрібен Python 3.11 або новіший.

### Windows PowerShell

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Заповніть `.env` реальними значеннями. Для локального запуску з Telegram webhook потрібна публічна HTTPS-адреса, тому для простого локального тесту зручніше спочатку розгорнути сервіс на Render. Не запускайте паралельно дві копії з одним токеном, бо обидві можуть намагатися керувати webhook.

Запуск сервера:

```powershell
uvicorn main:app --host 0.0.0.0 --port 8000
```

Для локального health check відкрийте `http://127.0.0.1:8000/`. Telegram не зможе надсилати webhook на localhost без публічного HTTPS endpoint.

## 5. Налаштування й адміністрування

- `MAX_IMAGE_MB=10` — максимальний розмір зображення.
- `USER_COOLDOWN_SECONDS=15` — пауза між запитами користувача.
- `MAX_DAILY_USER_REQUESTS=30` — ліміт на 24 години.
- `ADMIN_USER_IDS=123456789,987654321` — необов'язково: Telegram numeric user IDs адміністраторів, які обходять денний ліміт.
- `GEMINI_MODEL` — назва моделі, доступної вашому API key.
- `LOG_LEVEL=INFO` — рівень журналювання.

Не передавайте нікому `BOT_TOKEN`, `GEMINI_API_KEY` або `WEBHOOK_SECRET`. Якщо токен Telegram витік, перевипустіть його через BotFather.

## 6. Що означають CALL / PUT

- `CALL`: модель бачить певні ознаки руху вгору; це не гарантія.
- `PUT`: модель бачить певні ознаки руху вниз; це не гарантія.
- `НЕ ВХОДИТИ`: недостатньо даних, слабка якість, суперечливі сигнали або невизначеність.

«Узгодженість ознак» — лише якісна характеристика відповіді моделі, а не ймовірність успіху. Перевіряйте роботу на демо/історичних даних. Бінарні опціони можуть призвести до втрати всієї суми ставки.
